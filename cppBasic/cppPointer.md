# 포인터에 대해 알고 있는 대로 적기

**2026-08-11**

---

## 포인터란?

포인터란? 포인팅 해주는 것. 가르켜는 것.
무엇을 가르키냐하면, 주소를 가르키는 것이다.

이때 주소란, 포인터가 가르키는 변수의 메모리 주소를 의미한다.

예시는 아래와 같다.

```cpp
int a = 80;
int *ptr = &a;
```

`&`는 주소 연산자이다. `&a`처럼 사용시, 변수 `a`의 주소를 반환한다.

`ptr`이 `a`의 주소를 가르켜고 있다.

```cpp
cout << ptr;
```

이런식으로 사용시 `0xf123...` 과 같이 16진수로 이루어진 `a`의 주소가 반환된다.

만약 `a`의 값을 출력하고 싶다면 어떻게 할까?

```cpp
cout << *ptr;
```

결과:

```text
80
```

다음과 같이 `ptr`앞에 `*`를 붙여줌으로서 포인터가 가르키는 변수의 값을 얻어올수있다.

이때 `*`는 앞서 사용한 `int *`의 `*`과 달리 주소가 있는 지점의 값을 불러오는 **역참조 연산자**이다.

## 배열과 포인터

이번에는 배열과 포인터의 관계에 대해 알아보도록하자.

```cpp
int a[2] = {1, 2};
int b = 3;
int * ptr = &b;
```

다음과 같은 문장들이 있다.

이때 `a` 배열의 시작점의 주소를 알고 싶다고 하자.

방법은 두가지다.

```cpp
cout << a;
```

또는

```cpp
cout << &a[0];
```

어느쪽이든 `a`의 주솟값을 나타낸다.

만약 `ptr = a` 로 `ptr`에 배열 `a`의 주솟값을 담았다고 하자.

그렇다면 `ptr[0]`, `ptr[1]`과 같은 식들도 유효하다고 볼수 있다.

그렇다고 `a`가 포인터라는 건 아니고, 보통 배열의 이름 `a`는 배열의 첫번째 원소를 가리키는 포인터로 변환이 된다.

```cpp
*(ptr + 1)
```

은 이제 `2`가 된다.

배열에서 `a+1` 같이 이름으로 연산을 하면 해당하는 자료형의 바이트 값만큼 뒤로 이동해서 값을 읽어온다.

무슨 말이냐 함은

```cpp
*a == 1
*(a + 1) == 2
```

가 된다는 소리다.

(`a+1` 이 두번째 요소의 주솟값을 의미하므로)

사실상 `a[1]` 과 `*(a+1)`은 동등하다고 볼수 있다.

## const와 포인터

```cpp
const int a = 1
int const a = 1
```

위 두 식은 본질 적으로 차이가 없다.

두 식 모두 `a`의 값을 수정하는 것이 불가능하다.

다만, 포인터가 개입할시 의미가 크게 달라진다.

```cpp
const int * ptr
int const * ptr
```

둘다 `int` 자료형을 가진 변수의 주솟값을 담을 수 있는 포인터이다.

단, `const`가 `int`의 값을 보장해 주고 있기 때문에,
주솟값은 변경할 수 있지만, 포인터를 이용해 변수의 값은 변경이 불가능하다.

```cpp
int * const ptr
```

위와 달리, `const`가 `ptr` 자체를 상수화 시켜서 바꾸지 못하게함.

(변수의 값은 변경할 수 있지만, 주소는 변경이 불가능)

```cpp
const int * const ptr
int const * const ptr
```

변수의 값, 주소값 둘다 변경을 못하게 한다.

## nullptr

원래 포인터를 선언할떄는 초기화까지 시켜줘야한다. (안하면 위험)

근데 냅다 명시적 선언부터 때려버리고 싶다면 널포인터를 사용한다.

```cpp
int * ptr = nullptr;
```

비슷한 이치로 무슨 자료형의 포인터를 가리킬지 모르겠다? 하면 `void` 자료형을 사용해둔다.

```cpp
void * ptr = nullptr;
```

(사실상 이러면 아무것도 없다 ㅋㅋ)

## 함수 포인터

포인터로는 함수또한 가리킬수 있다?
(왜냐하면 함수도 주소값을 가지고 있을 것이기 때문에)

```cpp
int func(int a, int b) {return a+b;}
```

따위의 함수가 있다고 치자.

다음 함수는

```cpp
int (*fp)(int, int) = func;
```

처럼 가리킬수 있다.

사용법은 일반함수와 동일하다.

(왜냐하면? 결국 `fp`로 `func`의 주솟값을 담았따 => 동일한 연산을 수행한다.)

이기 때문에

```cpp
fp(20, 20)
```

하면 당연히 `40`이 튀어나온다.

여담으로 함수 포인터 배열도 사용이 된다.

```cpp
int (*fp[4])(int, int);
```

하고 막

```cpp
fp[0] = func1;
fp[1] = func2;
.....
```

etc 해버리면 된다.
